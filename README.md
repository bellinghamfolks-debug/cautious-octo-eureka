# رفيق الرؤية VisionBridge

تطبيق أندرويد أصلي بلغة Kotlin مخصص للمكفوفين وضعاف البصر. يلتقط، بعد موافقة المستخدم، ما يظهر في نافذة تطبيق النظارة أو على شاشة الهاتف باستخدام `MediaProjection`، ثم يقدّم:

- قراءة نص لحظية هجينة: OCR محلي سريع للنص اللاتيني، وGemini لاستعادة العربية والنص المختلط.
- وصف مشهد عملي يقدّم الخطر الواضح والاتجاهات النسبية والعوائق والنصوص المهمة.
- نطق آلي يقسم النص المختلط ويبدّل بين العربية والإنجليزية.
- حفظ مفتاح Gemini مشفراً بـ AES-GCM، مع المفتاح التشفيري داخل Android Keystore.
- خيار توجيه طلبات Gemini وحدها عبر البيانات الخلوية، دون ربط بقية التطبيق أو الهاتف بالشبكة الخلوية.
- واجهة Jetpack Compose مبسطة، بأهداف لمس كبيرة وتسميات واضحة لقارئ الشاشة TalkBack.

## البناء من GitHub

1. ارفع محتويات المشروع إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل **Android CI** أو ادفع أي تعديل إلى `main`.
4. بعد نجاح المهمة، افتح **Artifacts** وحمّل `VisionBridge-debug-apk`.

المسار الناتج داخل البناء:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## البناء بواسطة Codex أو محلياً

```bash
./scripts/codex-check.sh
```

هذا الأمر ينفذ فحص بنية المستودع وتسريب المفاتيح ثم:

```bash
./gradlew --no-daemon lintDebug testDebugUnitTest assembleDebug
```

المتطلبات: JDK 17 وAndroid SDK 35. يحتوي المشروع على Gradle bootstrap متوافقاً مع Gradle 8.9، بينما تستخدم GitHub Actions نسخة Gradle 8.9 المثبتة صراحةً.

## الاستخدام

1. افتح التطبيق وأدخل مفتاح Gemini ثم اختر **حفظ مشفّر**.
2. اختر وضع **قراءة النص** أو **وصف المشهد**.
3. اختر النموذج. الافتراضي `gemini-3.6-flash`، والبنية تدعم نماذج 3.1 و3.5 و3.6 من قائمة مركزية.
4. فعّل البيانات الخلوية حصرياً عند الحاجة.
5. اضغط **بدء التقاط الشاشة**.
6. في نافذة Android، اختر تطبيق النظارة الذي يعرض البث، أو الشاشة كاملة عند الحاجة.
7. لإيقاف الجلسة استخدم زر الإيقاف داخل التطبيق أو الإجراء الموجود في الإشعار.

## قرارات هندسية مهمة

- موافقة MediaProjection مطلوبة في كل جلسة، ولا يعاد استخدام رمز الموافقة بعد توقف الخدمة.
- الخدمة `START_NOT_STICKY` لأن النظام لا يسمح بإعادة إنشاء جلسة الالتقاط من رمز قديم بعد موت العملية.
- تسجيل `MediaProjection.Callback` يسبق إنشاء `VirtualDisplay`، وتحرر الشاشة الافتراضية و`ImageReader` عند الإيقاف.
- يجري أخذ أحدث إطار فقط، مع حد زمني واكتشاف تغير بصري 16×16 لتقليل استهلاك البطارية وطلبات الشبكة.
- لا يدعم ML Kit Text Recognition الحالي الخط العربي المطبوع، لذلك استُخدم OCR المحلي للنص اللاتيني وGemini للعربية والمختلط.
- لا يجري استدعاء `bindProcessToNetwork`. بدلاً منه تُربط `SocketFactory` وDNS لعميل طلب Gemini بالشبكة الخلوية المطلوبة فقط.
- لا يُخزّن المفتاح في الكود أو GitHub Secrets أو DataStore. التخزين المحلي هو ciphertext وIV فقط، والسر التشفيري غير قابل للتصدير من Keystore.

## حدود واقعية وسلامة

زمن الاستجابة السحابي يعتمد على الشبكة وحدود حساب Gemini. وصف صورة واحدة لا يمنح إدراك عمق موثوقاً ولا يضمن سلامة المسار. التطبيق أداة مساعدة إضافية، وليس بديلاً عن العصا البيضاء أو كلب الإرشاد أو التدريب على الحركة والتنقل أو التحقق البشري في الأماكن الخطرة.

قد تمنع بعض التطبيقات التقاط محتواها باستخدام `FLAG_SECURE`. وفي هذه الحالة ستظهر مساحة فارغة أو سوداء ولا يستطيع التطبيق تجاوز حماية النظام.

## بنية المشروع

```text
app/src/main/java/com/abdullah/visionbridge/
├── capture/        MediaProjection، تحويل الإطارات، منع التكرار
├── data/
│   ├── gemini/     REST وJSON وتحليل الصور
│   ├── network/    توجيه طلب محدد عبر Cellular Network
│   ├── ocr/        ML Kit OCR المحلي
│   ├── security/   Android Keystore وAES-GCM
│   ├── settings/   DataStore
│   └── speech/     TTS عربي وإنجليزي ومنع التكرار
├── domain/         النماذج والواجهات وحالات الاستخدام
├── di/             Dependency container بسيط وقابل للاختبار
└── ui/             ViewModel وCompose وTalkBack semantics
```

## الخصوصية

لا يحفظ التطبيق الإطارات على القرص. الإطار يعالج في الذاكرة ثم يعاد تدويره. عند استخدام Gemini، تُرسل صورة مضغوطة من الإطار إلى Google لتنفيذ التحليل وفق إعدادات وحساب المستخدم.
