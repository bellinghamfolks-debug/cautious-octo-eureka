# دليل نصوص واجهة VisionBridge

هذا الدليل هو المرجع المعتمد لأي نص جديد يظهر للمستخدم أو يقرأه TalkBack.

## النبرة

- العربية مباشرة وطبيعية، بلا ترجمة حرفية من الإنجليزية.
- تبدأ الرسالة بما يحتاج المستخدم إلى معرفته أو فعله.
- الرسائل القصيرة تذكر المشكلة ثم الإجراء المقترح، من دون تفاصيل هندسية لا تساعد المستخدم.
- لا تستخدم عبارات مبهمة مثل «المحرك المحلي» عندما يمكن تسمية التقنية بدقة.

## مصطلحات تبقى بالإنجليزية

تُكتب الأسماء والمصطلحات التالية بأصلها الإنجليزي، ولا تُعرّب صوتيًا:

- VisionBridge
- Gemini
- Gemini API Key
- OCR
- PP-OCRv5
- ONNX Runtime
- TalkBack
- MediaProjection
- eSight
- Share Your View
- TTS
- SSE
- XNNPACK
- HTTP
- JSON
- Markdown
- APK
- CI

أمثلة صحيحة:

- «فعّل Share Your View داخل تطبيق eSight».
- «تتم قراءة النص عبر PP-OCRv5 على الجهاز».
- «أضف Gemini API Key من الإعدادات».

أمثلة ممنوعة:

- «شير يور فيو».
- «إي سايت».
- «مفتاح واجهة برمجة تطبيقات جيمناي».
- «بوابة الثقة» بوصفها ترجمة حرفية لمفهوم OCR trust validation.

## مصطلحات عربية معتمدة

تستخدم العربية عندما يكون المقابل واضحًا وطبيعيًا:

- Screen sharing: مشاركة الشاشة
- Scene description: وصف المشهد
- Speech rate: سرعة النطق
- Mobile data: بيانات الجوال
- Diagnostics: التشخيص
- Model: النموذج
- On-device: على الجهاز
- Cloud processing: عبر الإنترنت، أو عبر Gemini عندما يكون ذلك أوضح

## الوصول عبر TalkBack

- يجب أن يصف `contentDescription` نتيجة الإجراء، لا شكل العنصر فقط.
- لا تكرر النص المرئي حرفيًا إذا كان قارئ الشاشة سيقرأه تلقائيًا.
- يذكر المفتاح أو الخيار حالته الحالية: «مفعّل» أو «غير مفعّل».
- لا تعتمد على الرموز وحدها لإيصال معنى الاختيار.
- عند ذكر العربية والإنجليزية في جملة واحدة، تبقى أسماء المنتجات بالإنجليزية لتجنب نطق عربي مضلل.

## نمط رسائل الأخطاء

الصيغة المفضلة:

1. ما الذي حدث؟
2. ما الخطوة العملية التالية؟

مثال:

«لا تصل صورة قابلة للتحليل. تأكد من أن شاشة الهاتف مضاءة وأن بث eSight ظاهر عليها. داخل تطبيق eSight، فعّل Share Your View.»
