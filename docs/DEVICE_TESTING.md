# الاختبار على أجهزة حقيقية (Firebase Test Lab)

## لماذا هذا موجود

يمكن محاكاة كل ما تحت مستوى النموذج على حاسوب: الهندسة، وترتيب الأسطر، وفك الترميز، واتجاه
النص ثنائي اللغة — وهذا كله مُحاكى فعلاً في `PaddleOcrPipelineTest`.

ما **لا يمكن** محاكاته أربعة أشياء، وكلها تظهر فقط على هاتف:

1. هل يحمّل ONNX Runtime النماذج الأربعة على معالج arm64 فعلي.
2. هل يُسجَّل XNNPACK فعلاً على هذا الجهاز.
3. هل يتسع الاستدلال في الذاكرة المتاحة.
4. هل تتحوّل البكسلات إلى المحارف الصحيحة من طرف إلى طرف.

## ما يغطيه كل نوع

| | اختبار الأجهزة (`PaddleOcrOnDeviceTest`) | Robo |
| --- | --- | --- |
| تحميل النماذج على arm64 | ✅ | ❌ |
| دقة القراءة فعلياً | ✅ | ❌ |
| المسافات بين الكلمات | ✅ | ❌ |
| ترتيب العربية المنطقي | ✅ | ❌ |
| الحروف المتباعدة (حالة العطر) | ✅ | ❌ |
| النص الصغير عند «أقصى دقة» | ✅ | ❌ |
| الانهيار عند التحرير أثناء القراءة | ✅ | ❌ |
| الانهيارات وتجمّد الواجهة أثناء التنقل | ❌ | ✅ |
| مسارات واجهة مسدودة | ❌ | ✅ |

**Robo وحده لا يصل إلى القارئ**: يحتاج موافقة التقاط الشاشة ثم يحتاج شيئاً يستحق القراءة، فأقصى ما
يفعله هو المشي في الواجهة. لهذا الاختبار الأول هو الأهم، وRobo مكمّل يبحث عن الانهيارات.

واختبار الأجهزة مصمّم ليعمل بلا مفتاح Gemini، وبلا إنترنت، وبلا موافقة التقاط شاشة — فهو يرسم النص
بمحرك الخطوط في أندرويد ثم يطلب من القارئ قراءته. لذلك يعمل بلا تدخل على مزرعة أجهزة.

## ما تحتاجه لتشغيله

سرّان في **Settings ← Secrets and variables ← Actions**:

| السر | ما هو |
| --- | --- |
| `GCP_PROJECT_ID` | معرّف مشروع Google Cloud |
| `GCP_SERVICE_ACCOUNT_KEY` | مفتاح حساب خدمة بصيغة JSON، بصلاحية `Firebase Test Lab Admin` و`Storage Object Admin` |

المشروع يحتاج تفعيل **Cloud Testing API** و**Cloud Tool Results API**، وحساب فوترة (الفئة المجانية
تكفي لتشغيلات قليلة يومياً).

ثم: **Actions ← Device test (Firebase Test Lab) ← Run workflow**.

## اختيار الأجهزة

الافتراضي جهاز افتراضي بمعمارية ARM بالعربية:

```
model=MediumPhone.arm,version=34,locale=ar,orientation=portrait
```

لتشغيل أكثر من جهاز افصل بينها بفاصلة منقوطة. تحقق من التوفر أولاً — كتالوج الأجهزة يتغيّر:

```bash
gcloud firebase test android models list
```

جهاز حقيقي أفضل من الافتراضي لقياس الأداء، لأن الافتراضي لا يمثّل معالج هاتفك.

## التكلفة

تُحسب بالدقيقة على مشروعك أنت، ولهذا التشغيل **يدوي** لا تلقائي مع كل دفعة.
